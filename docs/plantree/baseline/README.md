# Project Baseline

The repository publishes a host-neutral JSON delivery policy, thin host entrypoints, and a local stdio MCP controller. Plan Tree owns durable business planning; the controller owns rebuildable transactional projection, evidence indexes, authorization receipts, and recovery metadata. The JSON policy is the machine-checkable structural contract, while host instructions stay intentionally short.
