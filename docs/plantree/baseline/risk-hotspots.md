# Risk Hotspots

- Evidence surviving a scope change when it describes an obsolete implementation.
- Authorization consumption being mistaken for successful external execution.
- Arbitrary low-level patches bypassing high-level route intent.
- Policy, schemas, runtime constants and documentation drifting apart.
- A prompt, host-native plan, or Hook being mistaken for the authoritative structural protocol.
- A policy downgrade or unchecked migration relaxing controls on an in-flight strict flow.
- Human-authored Plan Tree prose being incorrectly frozen as controller drift, or a controlled state edit being silently accepted.
- Evidence paths or symlinks escaping the active Plan Tree root.
- Windows file locking and process termination between projection and SQLite commit.
- Local source updating without Codex cache or MCP activation updating.
