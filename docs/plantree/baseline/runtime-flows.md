# Runtime Flows

1. `engineering-workflow` routes a request and initializes or resumes a flow.
2. Delivery Control projects revisioned state into the selected Plan Tree target.
3. High-level operations advance route phases and project a native Codex plan.
4. Evidence, review, authorization and external-action results bind to the active delivery generation.
5. Close succeeds only when the current fixed point and terminal evidence satisfy every gate.
